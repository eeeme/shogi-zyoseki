# 定跡帳（shogi-zyoseki）

将棋の定跡を「分岐をたどって」覚えるための PWA。サーバー無し・端末内（IndexedDB）完結。

## 機能

- **定跡ツリー（フローチャート）**：手数は下へ、変化は右の列へフォークして表示。現在地までの経路を金色で強調、タップでその局面へ移動
- **閲覧・編集**：盤で指して手を追加（「編集」オン時）、本線の入れ替え、部分木の削除、各局面へのメモ
- **練習（暗記ドリル）**：先手／後手を選ぶと相手の手を自動で指し、自分の手番で定跡手を答える。間違えると再入力、「答えを見る」でヒント表示
  - 間隔反復（SM-2簡易版）で局面ごとに復習時期を管理。相手の手は「要復習・未学習」が多い変化を優先して選ぶ
  - 選択中の局面から練習／駒を隠す脳内盤モード／相手の手の読み上げ（カタカナ読み）
- **棋譜取込**：KIF・KI2（「変化」を分岐として取込）、CSA、USI/SFEN。既存の本へ統合（同じ手はマージ）。Shift_JIS の .kif も可
- **実戦照合**：自分の対局棋譜を貼ると、何手目で定跡を外れたか・定跡では何を指すかを表示
- **合流（手順前後）検出**：同じ局面が別手順で現れると ⇄ で表示し移動可能
- **KIFをコピー**：本全体を変化付きKIFとしてクリップボードへ（自由配置の本は局面図付き）
- **フォルダ**：本をフォルダにまとめる（本の「⋯」から移動）
- **タグ**：本にタグを付け、一覧で絞り込み（フォルダをまたいで表示）
- **対局情報**：棋譜の先手・後手・日付・棋戦・勝敗を取り込み、一覧と閲覧画面に表示（手で編集も可）
- **局面検索**：盤面を並べて、または閲覧中の局面から、全部の本を検索。完全一致と、駒配置の一致度が高い「似た局面」を盤面の縮小図付きで一覧表示
- **次の手の出現率**：全部の本で同じ局面（盤・持駒・手番が一致）の次の手を集計し、「67%・2局・勝率50%」を次の手に表示。2局未満の局面は出さない。勝率は勝敗のある棋譜だけで計算し、2局未満なら出さない。この本に無い手は点線で表示（✏オンで追加）
- **今日の復習**：「今日の復習に使う」をオンにしたフォルダの本だけが対象。復習日が来た局面から始めて、その変化を最後まで通して指す（相手の手は自動、自分の手番はすべて出題）。間違えた局面はその回の最後にもう一度
- **正解・不正解の演出**：盤の上に大きな◯／✕、変化を指し切ると「完」を表示
- **しおり**：局面にしおりを付けると、一覧の上に縮小盤面で並び、タップでその局面を開ける
- **スワイプ操作**：左へスワイプでツリー、上へスワイプでメモ。右へスワイプで前の画面に戻る（ツリーが開いているときはツリーを閉じるだけ）。メモは入力していないとき下へスワイプで閉じる
- **応援**：一覧の ♡ から。Google Play での評価・紹介と、アプリ版では Google Play の支払いで開発を応援（1回きり・機能は変わらない）
- **使い方の案内**：各画面を初めて開いたとき、説明する部品を光らせてタップで順に案内（一覧の「?」でもう一度見られる）
- **盤面編集**：駒箱から駒を自由に並べ、持駒・手番も設定してその局面から新しい本を作る。閲覧中の局面を並べ替えて作ることも可

## 制約（現状）

- 駒落ちは局面図付きのKIFで取り込む（手合割の名前だけでは未対応）
- 指し手判定は王手放置を見ない擬似合法手

## 開発

```bash
npm install
npm run dev     # 開発サーバー
npm test        # パーサー・盤ロジックのテスト
npm run build   # dist/ に出力
```

main への push で GitHub Actions がテスト→ビルド→GitHub Pages へデプロイします（リポジトリ設定 Pages の Source を「GitHub Actions」にしておく）。

## Android アプリ（Google Play）

Capacitor で包んでいます（パッケージ名 `com.meisme.jousekichou`）。

- `npm run android` … アプリ用にビルドして `android/` へ反映（Android Studio で開ける）
- GitHub の Actions →「Android (AAB)」→ Run workflow … 署名済み `.aab` を作って Artifacts に置く
  - 必要な Secrets：`ANDROID_KEYSTORE_BASE64`（アップロード鍵を base64 にしたもの）、`ANDROID_KEYSTORE_PASSWORD`
  - versionCode は実行番号、versionName は package.json の version
- アイコンの元画像は `assets/`（`npx capacitor-assets generate --android` で再生成）
- アプリ版だけの処理は `src/native.ts`（端末の戻るボタン、読み上げ、コピー、応援の支払い）
- 応援のアイテムは Play Console の「アプリ内アイテム」に `support_small` / `support_medium` / `support_large` で作る（消費型として扱う）

## 構成

```
src/shogi/     盤・指し手生成・SFEN/USI・日本語表記（表示/解析/読み上げ）
src/kifu/      棋譜パーサー（KIF/KI2/CSA/USI）と KIF 書き出し
src/book/      定跡ツリー（本）・間隔反復・IndexedDB 保存・サンプル
src/ui/        盤・ツリー・閲覧・練習・取込の各画面
```
